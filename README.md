# The Last Keeper of Eternia

Prototype RPG 2D browser untuk **The Last Keeper of Eternia**.

## Chapter 1 — The Clock That Should Not Tick
Prototype ini berisi:
- Desa awal Eternia
- Arkan Veyron sebagai karakter utama
- NPC dan dialog
- Old Shrine
- Jam saku kuno
- Memory Fragment
- Pertarungan turn-based pertama
- EXP dan level
- HUD dasar

## Menjalankan
Buka `index.html` di browser. Tidak membutuhkan server atau library eksternal.

## Kontrol
- WASD / Arrow Keys — bergerak
- E / Enter — interaksi
- J — menggunakan/menutup efek jam saku
- Esc — lanjut dialog
